Keyboard shortcuts
  • 1–4 switch layout
  • G cycle grade
  • F fill / fit the selected panel
  • R reset the selected panel crop
  • S shuffle all crops
  • E export PNG
  • C hold to compare without the grade
  • + / − zoom, arrow keys nudge the crop
